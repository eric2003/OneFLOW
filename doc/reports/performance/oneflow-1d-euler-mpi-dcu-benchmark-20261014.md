# OneFLOW 一维 Euler MPI/DCU 强扩展测试报告（2026-10-14）

> 状态：阶段性测试记录，未替换当前正式性能报告。  
> 范围：`ports/kunshan/oneflow_1d_hip` standalone 一维 Euler MPI 适配器。  
> 该报告不代表 OneFLOW 3D 主求解器、粘性/湍流、跨节点 MPI 或多 zone 路径已经完成
> DCU 验证。

## 1. 结论摘要

本轮在昆山计算节点完成了固定全局规模下的 CPU 与 DCU 强扩展测量：

- CPU MPI：1、2、4、8、16、32 ranks；
- DCU MPI：1、2、4 ranks，按一 rank 一张 DCU 记录，因此 2 ranks 对应 2 张 DCU；
- 全局网格：65,536、262,144、1,048,576、4,194,304；
- 每个配置 3 次样本，以下表格使用中位数；
- 所有配置使用相同的 `100 steps / 2 repeats / 1 warmup` 生命周期口径。

CPU 在四个规模上均保持良好的 32-rank 强扩展；DCU 在小规模受初始化、MPI 和
halo 固定开销影响明显，规模增大后扩展改善。4M 规模下，DCU 从 1 rank 扩展到
4 ranks 的 speedup 为 3.53×，效率为 88.3%。

## 2. 测试对象与口径

### 2.1 算例边界

这是 standalone 的一维 Euler 算例，不是 3D Navier–Stokes 主 solver。CPU 与 HIP
实现使用同一一维 Euler MPI 生命周期和相同初始条件、网格规模、步数及重复次数。
CPU 路径保留为数值 oracle；本轮没有将结果外推到其他物理模型或其他 backend。

### 2.2 环境与资源

| 项目 | CPU MPI | DCU MPI |
| --- | --- | --- |
| 目标平台 | 昆山计算节点 | 昆山计算节点 |
| 资源 | 单节点，32 CPU cores | 单节点，最多 4 张 DCU |
| MPI ranks | 1 / 2 / 4 / 8 / 16 / 32 | 1 / 2 / 4 |
| 设备映射 | CPU rank 绑定 core | 一 rank 一张 DCU |
| 加速器架构 | 不适用 | Hygon DCU，`gfx906` |
| 工具链 | GCC + OpenMPI 5.0.11 | DTK 26.04 + HIP + OpenMPI 5.0.11 |

性能指标为完整 `lifecycle_ms`，包含 benchmark 定义的初始化、数据准备、推进和
结果收尾；CPU 与 DCU 之间没有混用不同 `repeats` 口径。

## 4. DCU MPI 强扩展

单位：`lifecycle_ms` 中位数；1/2/4 ranks 分别对应 1/2/4 张 DCU。

| global_nx | 1 DCU | 2 DCU | 4 DCU |
|---:|---:|---:|---:|
| 65,536 | 74.12 | 72.97 | 72.00 |
| 262,144 | 113.43 | 92.83 | 81.83 |
| 1,048,576 | 270.17 | 170.46 | 119.65 |
| 4,194,304 | 978.03 | 540.02 | 277.06 |

相对 1-DCU 的强扩展：

| global_nx | 4-DCU speedup | efficiency |
|---:|---:|---:|
| 65,536 | 1.03× | 25.7% |
| 262,144 | 1.39× | 34.7% |
| 1,048,576 | 2.26× | 56.4% |
| 4,194,304 | 3.53× | 88.3% |

## 5. CPU/DCU 端到端对照

下表为 `CPU 32-rank lifecycle / DCU lifecycle`。大于 1 表示 DCU 更快，小于 1
表示 32-rank CPU 更快。

| global_nx | CPU32 / 1 DCU | CPU32 / 2 DCU | CPU32 / 4 DCU |
|---:|---:|---:|---:|
| 65,536 | 0.87× | 0.89× | 0.90× |
| 262,144 | 2.40× | 2.94× | 3.33× |
| 1,048,576 | 5.26× | 8.34× | 11.88× |
| 4,194,304 | 7.22× | 13.08× | 25.49× |

因此，小规模 65,536 上 CPU 32 ranks 略快，不能把 DCU 的固定启动和通信开销忽略；
从 262,144 开始 DCU 端到端优势出现，4M 规模下 4-DCU 达到 25.49×。

## 6. 正确性与可复核性

- 每个 CPU 配置均完成 3 个非空样本；四个全局规模共 72 个 CPU 样本。
- 每个 DCU 配置均完成 3 个样本；四个全局规模共 36 个 DCU 样本。
- MPI 分解检查通过，rank 数变化没有触发空分区。
- 各 rank 配置的最终状态 hash 一致；CPU 与 DCU 结果仍以 CPU oracle 和既有 HIP
  contract/regression 证据为准。
- 本报告只保留脱敏后的资源口径和测量结果，不包含节点名、作业号、私有路径或原始
  Slurm 日志。

## 7. 限制与后续

1. 这是单节点 standalone 一维 Euler MPI 端口的强扩展测试，不是 3D 主 solver 性能结论。
2. 尚未覆盖跨节点 MPI、跨节点 GPU 通信、粘性/湍流、多 zone 或其他 accelerator backend。
3. 端到端比值包含初始化、MPI 和 halo 固定成本；不能解释为单个 HIP kernel 的加速比。
4. 趋势图使用同一份中位数矩阵绘制，适合观察扩展趋势，不替代 correctness 或
   MPI contract 测试。
