OneFLOW
=======

This page is a short entry point to the project documentation. OneFLOW is an evolving open-source codebase for computational fluid dynamics (CFD) and scientific computing.

The repository includes C++ runtime components, mesh and case-processing workflows, numerical methods, tests, and optional developer tools. The supported capabilities and maturity of individual solvers, numerical schemes, platforms, and acceleration backends vary by revision and build configuration; consult the code, tests, and relevant runbooks rather than inferring support from a design goal alone.

Start here:

* :doc:`index` — project overview and documentation navigation.
* :doc:`mesh_architecture` — mesh information model, snapshots, and format adapters.
* :doc:`grid_topology` — topology contracts, boundary normalization, and derived connectivity.
* :doc:`workbench_architecture` — project, case, workflow, and run-lifecycle design.

For build and execution instructions, use the repository README and the relevant installation or runbook documentation for the current revision.
